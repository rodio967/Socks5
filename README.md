# SOCKS5 Proxy Server

## Описание
SOCKS5 прокси-сервер на Java NIO. Использует Selector event loop для высокопроизводительного мультиплексирования I/O.

Socks5 Server поддерживает как протокол без аутентификации, так и протокол с аутентификацией.
Для выбора типа нужно в файле `users.properties` в первой строке выбрать тип `type=NO_AUT` или `type=AUTH`.

Логин и пароль задаются в `users.properties`.

**Пример:**
- type=NO_AUTH
- abc=1234567


## Возможности

- **Протокол SOCKS5** — команда `CONNECT`
- **IPv4, IPv6, доменные имена** — все типы адресов
- **Асинхронное DNS** через UDP с автоматическими повторами
- **Неблокирующий I/O** через Java NIO `Selector`
- **Graceful TCP shutdown** — двунаправленное полузакрытие


Java 21+


## Запуск

Для запуска программы нужно указать номер порта и имя файла, где находятся логин-пароль

**Пример:**

```bash
./gradlew run --args="port users.properties"
```
